# M365 Scripts

This folder contains scripts for Microsoft 365 tenant administration tasks that span Microsoft Graph and Entra ID services.

## Scripts

- [Invoke-M365LicenseManagement](Invoke-M365LicenseManagement/README.md): Interactively reviews, exports, replaces, and restores Microsoft 365 license assignments.

## Layout

Each script directory contains the PowerShell script and a README with requirements, parameters, examples, outputs, and safety notes.
