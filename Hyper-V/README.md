# Hyper-V Scripts

This folder contains scripts focused on Hyper-V host and virtual machine diagnostics.

## Scripts

- [Get-HyperVOrphanAvhdx](Get-HyperVOrphanAvhdx/README.md): Reports orphaned AVHD/AVHDX differencing disks and broken disk chains. Read-only.

## Layout

Each script directory contains the PowerShell script and a README with requirements, parameters, examples, and output details.
